# Nitori Secret Lab Music Player

Offline music player Android dengan queue "Up next" yang bisa diatur (reorder, remove, tap-to-play) dan shuffle yang lebih baik.

## Status
Skeleton project sudah ada (belum dibuka/di-build di Android Studio). Fitur belum diimplementasi.
